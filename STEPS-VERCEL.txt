⚠️ PEHLE YE PADHO (IMPORTANT):

Vercel "serverless" hai — normal Node server 24x7 nahi chalta.
Iska matlab ClientHub ke 2 features Vercel pe KAAM NAHI karenge:

   ❌ Socket.io (real-time notifications) — bell icon pe live
      notification nahi aayega (page refresh karne pe dikhega)
   ❌ node-cron (weekly AI report auto-generate) — auto nahi
      chalega (button se manually generate hota rahega)

Baaki SAB kaam karega: login, clients, projects, kanban,
invoices, PDF, payments, AI summary (manual), dark mode, etc.

Database Vercel pe nahi hota — Neon (free) use karenge.
Total 3 cheezein: GitHub (code) + Neon (database) + Vercel (app)

STEP 3 — BACKEND (API) VERCEL PE DEPLOY KARO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pehle ek chhota code change chahiye — Vercel ko ek entry file
chahiye jo Express app ko serverless function bana de.

1. Ye file banao:  server/api/index.js
   Content (sirf 2 lines):

   import app from '../src/app.js';
   export default app;

2. Ye file banao:  server/vercel.json
   Content:

   {
     "version": 2,
     "builds": [{ "src": "api/index.js", "use": "@vercel/node" }],
     "routes": [{ "src": "/(.*)", "dest": "/api/index.js" }]
   }

3. Commit + push karo:

   cd C:\Users\Admin\Desktop\CLIENTHUB\CLIENTHUB\clienthub
   git add server/api/index.js server/vercel.json
   git commit -m "Add Vercel serverless entry for API"
   git push

4. https://vercel.com pe jao → Sign up (GitHub se)
5. "Add New..." → "Project" → repo import karo: Project---Client-Hub
6. Configure:
       Project Name:     clienthub-api
       Root Directory:   server        ← IMPORTANT! "Edit" pe click karke select karo
       Framework Preset: Other
       Build Command:    npx prisma generate
       Install Command:  npm install

7. Environment Variables add karo:

   DATABASE_URL         = [Neon connection string, Step 2 wala]
   JWT_SECRET           = MyStr0ngS3cr3tKey2026ForClientHub!xyz
   NODE_ENV             = production
   CLIENT_URL           = https://clienthub.vercel.app    ← Step 4 ke baad sahi karna
   GROQ_API_KEY         = [apni Groq key — server/.env file me se copy karo]
   GROQ_MODEL           = llama-3.3-70b-versatile
   IMAGEKIT_PUBLIC_KEY  = [apni ImageKit public key — server/.env me se]
   IMAGEKIT_PRIVATE_KEY = [apni ImageKit private key — server/.env me se]
   IMAGEKIT_URL_ENDPOINT= [apna ImageKit URL endpoint — server/.env me se]

8. "Deploy" click karo
9. URL milega, e.g.: https://clienthub-api.vercel.app
   Test karo browser me:  https://clienthub-api.vercel.app/api/health
   Ye aana chahiye: {"status":"ok","database":"ok",...}

   Save karo → Deployments tab → latest pe "Redeploy" karo
