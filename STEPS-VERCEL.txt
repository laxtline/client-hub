  ⬜ JO BAAKI HAI (in steps ke liye tumhari permission chahiye)
------------------------------------------------------------

STEP A — DATABASE (Neon Postgres)
   Vercel dashboard → Storage → Create Database → Neon → region
   Singapore (ap-southeast-1) → connect to BOTH projects.
   Phir local se schema + demo data ek baar daalo:

     cd C:\Users\Admin\Desktop\CLIENTHUB\CLIENTHUB\clienthub\server
     DATABASE_URL="<NEON_URL>" npx prisma db push
     DATABASE_URL="<NEON_URL>" npm run seed

STEP B — API KE ENVIRONMENT VARIABLES
   Values server/.env me already maujood hain (copy kar lo).
   Vercel → clienthub-api → Settings → Environment Variables
   (Production), ya CLI se:

     cd server
     vercel env add DATABASE_URL production
     vercel env add JWT_SECRET production
     vercel env add NODE_ENV production           # value: production
     vercel env add CLIENT_URL production         # value: https://clienthub-laxtline.vercel.app
     vercel env add GROQ_API_KEY production
     vercel env add GROQ_MODEL production         # value: llama-3.3-70b-versatile
     vercel env add IMAGEKIT_PUBLIC_KEY production
     vercel env add IMAGEKIT_PRIVATE_KEY production
     vercel env add IMAGEKIT_URL_ENDPOINT production

   Note: JWT_SECRET production me 32+ random chars hona chahiye,
   warna server boot pe fail karega (validateEnv.js).

STEP C — API DEPLOY + ALIAS
     cd server
     vercel deploy --prod --yes
     vercel alias set <deployment-url> clienthub-api-laxtline.vercel.app

   Test:  https://clienthub-api-laxtline.vercel.app/api/health
   Aana chahiye: {"status":"ok","database":"ok",...}

STEP D — FRONTEND KO API SE JODO
     cd client
     vercel env add VITE_API_URL production      # https://clienthub-api-laxtline.vercel.app/api
     vercel env add VITE_SOCKET_URL production   # https://clienthub-api-laxtline.vercel.app
     vercel deploy --prod --yes
     vercel alias set <deployment-url> clienthub-laxtline.vercel.app

STEP E — SSO PROTECTION HATAO (site public karne ke liye)
   Abhi frontend URL Vercel login ke peeche hai (302 → sso-api).
   Vercel → clienthub → Settings → Deployment Protection →
   Vercel Authentication = Disabled. Ya CLI se:

     vercel project protection disable clienthub --sso

   (Yahi clienthub-api ke liye bhi karo, warna frontend API ko
   call nahi kar payega.)

STEP F — AUTO-DEPLOY ON GIT PUSH (tumhari main requirement)
   CLI se connect fail hua kyunki Vercel ka GitHub App tumhare
   account pe install nahi hai. Ek baar browser se karo:

   1. https://vercel.com/laxtline-8090s-projects/clienthub/settings/git
   2. "Connect Git Repository" → GitHub → Install Vercel app →
      repo chuno: laxtline/client-hub
   3. Root Directory = client   (Settings → Build & Deployment)
   4. Wahi clienthub-api project me repeat karo, Root Directory = server

   Iske baad: GitHub pe push → dono project apne aap redeploy.
